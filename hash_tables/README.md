# C - Hash tables
Holberton/ALX project: Hash tables using separate chaining.
- Toolchain: gcc -Wall -Werror -Wextra -pedantic -std=gnu89
- Style: Betty (betty-style.pl, betty-doc.pl)
- No globals, ≤ 5 functions per file, header guarded.

Files:
- 0-hash_table_create.c: create hash table
- 1-djb2.c: djb2 hash
- 2-key_index.c: key -> index
- 3-hash_table_set.c: set/update (chaining at head)
- 4-hash_table_get.c: get by key
- 5-hash_table_print.c: print as {'k': 'v', ...}
- 6-hash_table_delete.c: free all
- hash_tables.h: structs & prototypes
